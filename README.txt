
پروژه نمایش اشعار احمد ظاهر - نسخه HTML آفلاین

✅ فایل‌ها:
- index.html : نمایش‌دهنده اشعار
- احمد_ظاهر_شعرها.json : اشعار در قالب JSON
- README.txt : راهنمای اجرا

📌 اجرای پروژه:
۱. در همان فولدر، Shift + Right Click بزنید و گزینه "Open PowerShell window here" را بزنید.
۲. دستور زیر را وارد کنید:

python -m http.server 8000

۳. مرورگر را باز کنید و بروید به:

http://localhost:8000

✅ حالا اشعار را خواهید دید.
